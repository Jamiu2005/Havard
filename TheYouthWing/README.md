# SUDAI Youth Wing Website

A modern, responsive website for the Shams-Ud-Deen Al-Islamiy Youth Wing organization. This website showcases the organization's mission, objectives, and programs while providing an easy way for members and interested individuals to get involved.

## Features

- Responsive design that works on all devices
- Modern and clean user interface
- Interactive elements and smooth animations
- Newsletter subscription form
- Real-time prayer time display
- Mobile-friendly navigation
- Sections for About, Objectives, Programs, and Get Involved

## Technologies Used

- HTML5
- CSS3 (with CSS Variables and Flexbox/Grid)
- JavaScript (Vanilla JS)
- Font Awesome Icons
- Google Fonts (Poppins)

## Setup Instructions

1. Clone this repository to your local machine
2. Ensure you have a modern web browser installed
3. Open the `index.html` file in your browser to view the website

### Development

To make changes to the website:

1. Edit the HTML in `index.html`
2. Modify styles in `styles/main.css`
3. Update JavaScript functionality in `js/main.js`

## Customization

### Colors
The website uses CSS variables for easy color customization. You can modify the colors in the `:root` section of `main.css`:

```css
:root {
    --primary-color: #2c3e50;
    --secondary-color: #27ae60;
    --accent-color: #e74c3c;
    --text-color: #333;
    --light-bg: #f5f6fa;
    --white: #ffffff;
}
```

### Images
Replace the hero background image in the `images` directory with your own image and update the path in `main.css`.
